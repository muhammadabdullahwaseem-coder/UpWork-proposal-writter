# Nex-Link — URL Shortener

## Tech Stack
MongoDB, Express.js, React.js, Node.js (MERN)

## Overview
A full-stack URL shortening service built as a personal project to demonstrate core MERN stack competency: REST API design, database schema for short-code/URL mapping, redirect handling, and a React frontend for link creation and management.

## Relevant For Job Posts Mentioning
MERN stack, Node.js, Express, MongoDB, React, REST APIs, backend development, full-stack JavaScript development.
